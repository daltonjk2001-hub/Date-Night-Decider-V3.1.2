Frequently Asked Questions

How does Matcher mode work?

Both players review date cards. Shared likes become mutual matches, and multiple matches can continue into the elimination draft. Local progress remains on the device unless live synchronization is active.

Why is there a storage warning?

The warning means IndexedDB or the Dexie library could not be used. In that situation, the app temporarily keeps data in memory, so scrapbook entries and preferences can be lost on close or reload. Export a JSON backup if the data is still available, then retry with browser storage enabled and the required vendor files loaded.

Does Live Couple Room always connect?

No. The default static configuration uses public PeerJS signaling and STUN-only connectivity unless the operator deploys a private PeerJS signaling server and an authenticated TURN-credential endpoint. Some cellular, campus, workplace, or restrictive networks may block direct WebRTC connections. Connection resilience preserves local state where possible, but live sync is not guaranteed.

How do I restore expansion purchases?

In a configured iOS/Android build, open Settings and select Restore Purchases. The app checks RevenueCat customer information and restores only entitlements reported by that service. Browser-only use cannot verify native store ownership. If purchases are missing, confirm you are signed in to the same Apple/Google store account and contact support with the product name and a transaction reference—never send payment credentials.

Can I use the app offline?

The service worker caches app files and successfully loaded vendor assets. First launch without internet is only reliable when the Dexie and PeerJS vendor files are packaged under vendor/. If a vendor file was not bundled and was never cached, first startup requires internet. A storage warning means persistent data is not available.

How do I edit or delete a scrapbook item?

Open Scrapbook/History, then use the Edit or Delete controls on the entry. Export a backup periodically if you want an independent copy of your data.
