Legal & Privacy

Privacy Policy & Support

Local-first storage: Scrapbook entries, filters, and preferences are stored in browser/native IndexedDB when available. If storage fails, an alert banner is displayed and unsaved work is not claimed to be preserved.

Live rooms: Live sync sends room setup and selected date-card state between participants using PeerJS/WebRTC. Default setup uses public STUN with dynamic TURN relay credential endpoint support.

Purchases: In-app purchases process securely via App Store / Google Play and RevenueCat.
